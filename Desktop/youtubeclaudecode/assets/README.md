# assets/ — Shared Assets

Tài nguyên dùng chung cho mọi kênh.

## Cấu trúc

```
assets/
├── fonts/        ← Font files (Cinzel, Playfair Display — tải từ Google Fonts)
├── logos/        ← Channel logos, watermarks
└── templates/    ← Canva templates, Premiere presets
```

## Fonts

Tải miễn phí từ Google Fonts:
- [Cinzel](https://fonts.google.com/specimen/Cinzel) — Title text (Bold, ALL CAPS)
- [Cinzel Decorative](https://fonts.google.com/specimen/Cinzel+Decorative) — Alternative title
- [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) — Subtitle text

## Cách thêm asset

```bash
# Fonts: tải .ttf/.otf → đặt vào assets/fonts/
# Logos: xuất .png/.svg → đặt vào assets/logos/
# Templates: lưu .canvas/.prproj → đặt vào assets/templates/
```
