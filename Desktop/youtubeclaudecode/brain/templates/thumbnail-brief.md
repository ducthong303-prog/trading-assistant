# Thumbnail Design Brief Template

> **Reference:** brain/prompts/style-signature.md for typography & colors
> **Tool:** Google Flow (Imagen 4) + Canva post-production

---

## 6 PROVEN PATTERNS

| Pattern | Viral Rate | Layout | Best For |
|---------|-----------|--------|----------|
| A — Every X Explained | 40% | Title top + character center | Series, listicles |
| B — Title Statement | 25% | Big statement + visual scene | Deep dives |
| C — Contrast/Comparison | 10% | Split left/right | Two-sided topics |
| D — Character Grid | 10% | 6-12 portrait grid | Multi-person bios |
| E — Quote/Concept Block | 10% | Quote + supporting scene | Theological concepts |
| F — Icon Row with Labels | 5% | 3-5 icons in sequence | Process/sequence |

---

## OUTPUT PER VIDEO

```
3 Variations × 2 Versions = 6 Prompts

Version 1: WITH text (AI tries to render text in image — 50/50 success)
Version 2: NO text (visual only, add text in Canva — 100% reliable)
```

## TYPOGRAPHY SPECS

```
PRIMARY TITLE:
├── Font: Cinzel Bold (Google Fonts, free)
├── Size: 120-180pt
├── Color: #1E2A4A (Deep Navy)
├── Case: ALL CAPS
└── Position: Top 30-40% of frame

SUBHEADER ("EXPLAINED"):
├── Font: Cinzel/Playfair (lighter weight)
├── Size: 70-100pt
├── Color: #B25D29 (Burnt Orange)
├── Case: ALL CAPS
└── Position: Below primary title

SMALL TEXT (locations, dates):
├── Font: Same family, regular weight
├── Size: 30-50pt
├── Color: #1E2A4A or #8B6F47
└── Position: Bottom or corners
```

---

## PATTERN SELECTION LOGIC

```
IF title starts with "Every X" AND character-focused → Pattern A
IF title is question/statement AND tells story → Pattern B
IF content compares 2 things → Pattern C
IF topic is multiple people/things → Pattern D
IF title is counterintuitive concept → Pattern E
IF content is progression/sequence → Pattern F

→ Always pick 3 DIFFERENT patterns for A/B testing
```

---

## POSTAGE STAMP TEST

```
□ View thumbnail at 1/8 size (~160×90px)
□ Can you tell what video is about?
□ Is text readable?
□ YES → ready | NO → increase text, simplify visual
```
