# brain/templates/ — Reusable Templates

Template chuẩn cho từng loại output.

## Files

| File | Dùng khi |
|------|----------|
| `script-template.md` | Viết kịch bản mới — cấu trúc 3-Act, banned vocabulary, retention phrases |
| `image-prompt-template.md` | Tạo prompt ảnh — cấu trúc prompt, consistency method, density guide |
| `thumbnail-brief.md` | Thiết kế thumbnail — 6 patterns, typography specs, A/B test strategy |

## Cách dùng

Mỗi template chứa:
- Cấu trúc chuẩn (fill-in-the-blanks)
- Example đã verify
- Checklist trước khi output
- Reference đến `brain/prompts/` cho style/colors
