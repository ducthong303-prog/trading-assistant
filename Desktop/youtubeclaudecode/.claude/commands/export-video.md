# /export-video — Publishing Checklist

Hiển thị checklist xuất bản video lên YouTube.

## Publishing Checklist

### Audio
- [ ] Script đã clean (zero brackets)
- [ ] Đã copy vào ElevenLabs/TTS
- [ ] Đã generate voiceover file
- [ ] Đã kiểm tra pronunciation (Hebrew/Greek words)

### Visual
- [ ] Đã generate tất cả ảnh trong Google Flow
- [ ] Đã kiểm tra character consistency
- [ ] Đã import vào editor (CapCut/Premiere)
- [ ] Đã sync audio + visual

### Thumbnail
- [ ] Đã chọn variation tốt nhất
- [ ] Đã thêm text trong Canva (nếu dùng Version 2)
- [ ] Font: Cinzel Bold (title) + Cinzel/Playfair (subtitle)
- [ ] Colors: deep navy #1E2A4A + burnt orange #B25D29
- [ ] Background: cream #F5EBD8

### YouTube Upload
- [ ] Title: đúng format "Every X Explained"
- [ ] Description: có timestamps + scripture references
- [ ] Tags: Bible explainer, Christian, [topic-specific]
- [ ] Thumbnail: đã upload
- [ ] Playlist: đã thêm vào đúng playlist
- [ ] A/B test: đã setup 3 thumbnails (nếu có)

### Post-Upload (7-14 days)
- [ ] Kiểm tra CTR sau 24h
- [ ] Kiểm tra CTR sau 7 ngày
- [ ] Chọn winning thumbnail
- [ ] Ghi nhận pattern winner cho video tiếp theo

## Trigger

Gọi khi user nhắn: "xuất bản", "publish", "checklist", "checklist đăng video", "export video"
