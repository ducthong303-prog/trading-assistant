# /competitor-check — Phân Tích Đối Thủ

Phân tích nhanh kênh đối thủ Bible Explainer để lấy insight.

## Flow

1. Hỏi user: **Kênh nào?** (tên kênh hoặc URL)
2. WebSearch/WebFetch kênh đó.
3. Phân tích:
   - Upload frequency
   - View count trend
   - Thumbnail style
   - Title pattern
   - Description structure
   - Engagement rate
4. So sánh với benchmarks:
   - Deep Made Simple (144K)
   - Bible Made Simple (9.33K)
   - Plain Truth (5.97K)
5. Đề xuất: pattern nào đáng test cho kênh của mình.

## Trigger

Gọi khi user nhắn: "đối thủ", "competitor", "phân tích kênh", "check kênh [name]"
